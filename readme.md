# Oil Painter  [0.1.0] 

Oil Painter is a image manipulation program written in **Rust** which converts normal image into oil-painted image by applying filter

## Why would someone need this?

Recently , i saw a trend of mac users specially using oil painted wallpapers which looked cool and aesthetic to me but not everyone were fan of those premade wallpapers so to allow users to create custom oil-painted wallpaper/images, Oil Painter was developed.Its a simple lightweight program that takes an image , asks for a output path( which you have to write manually) and creates a oil-painted variant of it

## How to use it

To use Oil painter , download the release file from the release section and run it

it will ask the following inputs:

1. Input Image Location - The image you want to oil paint 
2. Output Image Location - The location you want to see your output <br>
(**Note: It should be written manually along with the image format like `output_file_name.png`**)
3. Brush Radius - How much area the brush should cover ( Default 4 )
